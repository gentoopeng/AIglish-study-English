# 通信量と保存先

ハンバーガーメニューの「通信量と保存先」から確認できます。
表示はこの端末・このブラウザーの推定値で、Firebase全体の使用量・残量・請求値ではありません。
SDKの取得・リスナーの配信・トランザクション、Firestore RESTの応答を分類します。
キャッシュ、再試行、内部SDKアクセス、インデックス課金等により実際の課金回数とは異なります。
日本時間で日別に端末内へ14日分保持します。無料枠のリセット時刻とは一致しません。
計測結果をFirebaseには保存せず、REST応答も複製せず読み取り時に数えます。

| 内容 | 保存先 | 反映タイミング |
| --- | --- | --- |
| 教材本文・ワーク問題と答え | 端末のIndexedDB＋Firebase | 開いた教材を自動取得、変更本文は終了・セーブで同期 |
| 理解度・個人メモ・付箋・復習 | 端末＋Firebase | 端末は操作時、クラウドは終了・スリープ・手動セーブ |
| 勉強時間・学習カウンター | 端末＋Firebase | 計測を端末に保持、終了・スリープ・手動セーブで同期 |
| フラッシュ中断位置 | 端末のみ | 操作時に記録、同じ端末で再開 |
| プロフィール・写真・フレーム | 端末＋Firebase | プロフィール保存・装備時 |
| 共有メモ・公開教材 | Firebase＋端末キャッシュ | 公開操作時 |
| フレンド・グループ | Firebase＋一部端末キャッシュ | 追加・変更操作時 |
| チャット本文 | Firebase | メッセージ送信時（学習終了時セーブとは別） |
| チャット下書き | 端末のみ | 入力後に端末へ保存。送信成功時に消去 |
| 対戦部屋・スコア・レート | Firebase＋一部端末記録 | 対戦中と結果確定時 |
| リーダーの文章・履歴・本棚 | 端末＋Firebase | 終了・全体セーブ |
| APIキー | 端末＋Firebaseの全体セーブ | 設定・全体セーブ。ファイルバックアップからは除外 |
| 背景・音楽・効果音のファイル | GitHub Pages | 配信ファイル。選択設定は端末、一部は全体セーブにも含む |
| 通信量の推定記録 | 端末のみ | 自動集計、Firebase送信なし |
| JSONファイルのバックアップ | ユーザーが選んだファイル | 明示的な書き出し。iCloud Driveを選んだ場合もFirebaseとは別 |

端末保存はSafari/PWA内のストレージです。「ファイル」アプリに見えるファイルとは別です。
タブを閉じても通常残りますが、サイトデータ削除やOSによる削除に備えたファイル書き出しも利用できます。
この変更では既存の学習データの移行・削除・リセットは行いません。

# 管理者一覧

通常ユーザー一覧と共有の走査待ち列から分離し、RESTで名前・削除状態だけを25件ずつ取得します。
詳細も編集対象フィールドのみ取得します。全体を15秒で打ち切り、エラー・再試行を表示し、閉じる操作は有効にします。
編集・レートリセット・完全削除・削除アカウントへの書き込み防止は維持します。
完全削除では本人のチャットメッセージも対象にします。

# グループチャット

`studyGroups/{group}/messages/{messageId}` に保存します。送信ごとに所属とアカウントを確認します。
最新30件を受信し、以前の履歴は30件ずつ明示取得します。グループを閉じる・別画面へ移動・非表示中は監視を停止します。
学習目標の更新でも入力欄を再構築せず、下書きを保持します。通信失敗時も入力を消しません。
再試行は同じメッセージIDで行い、同じ内容の重複作成を避けます。
送信はグループ・アカウントの読取とメッセージの書込、受信は参加者の表示中の通信を使用します。
Firebase本番のセキュリティルール・実機Safariは別途本番での検証が必要です。
