# 単語バトル

フレンド欄の「単語バトル」から全画面で一人プレイ、部屋作成、6桁の部屋番号による参加ができます。部屋の待機期限は2分、参加後は3秒のカウントダウンと60秒の試合です。ホストが選んだ単語帳全体から異なる意味を持つ最大120語を端末内で抽選し、両者に同じ問題順を出します。意味は先頭の意味を使用します。問題の単語は一巡するまで重複を避け、選択肢を順に入れ替えます。10語程度の小さな単語帳では選択肢の重複は避けられません。問題ごとの単語帳読み込みはありません。

9択と「選択肢の中にはない」の10択です。正解は100→110→120…点、ミスは−50点とコンボ解除。一人プレイではレートを変更しません。正解は出題した意味の理解度○、不正解は×に反映します。対戦はElo（初期1500、K=32）、同点は引き分けです。退出・アプリ非表示は途中退出として扱います。

レートはヘッダーの時計右、ユーザー詳細、ランキングの「単語バトル」に表示します。対戦中は勉強時間の計測対象です。

プレイヤーのアイコンと装備中のフレームを表示します。アイコンは取得済みのユーザー一覧を優先し、必要な場合のみ相手のプロフィールを1回読みます。画像を部屋の更新データには含めず、キャッシュは最大4人・5分です。コンボの短い演出と残り時間のバーを追加し、動きを減らす設定も尊重します。ミス時は選択肢の正解と正しい意味を表示し、次へ進むまで回答を無効にします。確認中も時間は進みます。

## 回答からの理解度保存

出題データに単語帳ID・単語番号・意味ID・単語の署名を持たせます。回答時はLearningData.commitの明示的回答として、対象の意味だけ○／×と履歴を更新します。他の意味、メモ、他の単語帳を保持します。単語帳の切替や全件の初期化を行いません。読み込み前、アカウント不一致、単語の署名変更、壊れた保存データでは上書きを停止します。

端末の通常理解度と復旧用コピーへ毎回答保存し、未同期の単語番号・意味ID・リビジョンをcore_v4_word_duel_pending_{ID}に残します。このキーもIndexedDBにミラーし、統合セーブの古い値で置換しません。5回答ごと・終了時のトランザクションで対象のvocabProgressドキュメントにマージします。クラウドの別の単語・意味・メモ、新しい編集時刻を保持します。失敗時と保存中の追加回答は未同期のまま残し、起動・オンライン復帰・1分ごとの確認で再試行します。ゲストは端末内のみです。

選択したボタンをハイライトし、正解時は180ms後に次の問題へ進みます。この間は回答をロックします。不正解時は正しい意味と「次の問題」を表示します。英語の装飾見出しを廃止し、アプリの共通背景と単色の半透明パネルを使います。

## シングルプレイのベスト

60秒完走時のみ自己ベストを保存します。途中終了・アプリ非表示は対象外です。単語帳共通のスコアランキングです。0点・負のスコアも完走記録として扱い、未プレイと区別します。

端末の `core_v4_word_duel_solo_{ID}` に記録と未同期フラグを保存し、IndexedDBにもミラーします。ログイン中はユーザードキュメントの `wordDuelSoloBest`、`wordDuelSoloBook`、`wordDuelSoloBestAt` のみをトランザクションで更新します。小さい記録では書き込まず、クラウドの大きい記録は保持します。失敗時は未同期フラグを残し、起動・オンライン復帰・画面復帰時に再試行します。ゲストは端末内のみです。ベストスコア保存ではレートや理解度を変更しません。理解度は回答時の専用処理で保存します。

ランキングの「単語バトル」で、対戦レートとシングルの表彰台を同じ画面に表示します。このグループを開いた時だけ必要なフィールドを取得し、学習ランキングとは別にキャッシュします。直近1か月のログイン条件は docs/firestore-read-budget.md を参照してください。

## 通信と保存

既存のFirestoreで `wordDuelRooms/{6桁番号}` を作成します。出題方式を変更したため部屋の形式はversion 3です。旧版の部屋とは接続できず、両者とも最新版に更新して作り直す必要があります。監視は参加中の1部屋だけです。回答は250msの待機と通信中のまとめ送りで同期し、終了時に最終回答を送ります。部屋を閉じる・試合終了で監視とタイマーを停止します。部屋一覧を定期取得しません。ただし対戦中は回答同期に伴う読み取り・書き込みが増えます。

試合結果と両者の `users/{ID}` の `wordDuelRating`、`wordDuelGames` を同じトランザクションで確定し、確定済み試合の再集計を防ぎます。結果確定では理解度・単語帳・ワークを変更しません。回答時の理解度反映では、その単語だけを更新し、理解度を付けた単語数に含めます。通信失敗時は結果を再確認するボタンを表示し、成功扱いにはしません。

通信断や強制終了の退出送信は保証できません。終了時刻から7秒後にも終了記録がない参加者は途中退出として集計します。端末時計を使用するため時計のずれの影響があります。終了済み部屋の自動削除は未設定です。

## 検証と本番での制約

Chromium・WebKitの2画面で全画面表示（393px・320px）、フレーム付きアイコン、ミス時の正解表示と回答無効化、ベストスコアの同期・ランキング、途中終了・低スコア時の記録維持を確認しました。同一問題、相手スコア更新、60秒終了、コンボと減点、Elo更新、二重集計防止、既存学習フィールドの維持も確認しています。保存容量エラー・再起動・アカウント変更・同期待ち中の新記録もテストしています。ブラウザーテストは共有メモリー上のFirestore代替を使用し、本番Firestoreへの書き込みは行っていません。

本番の新規部屋パスへの読み取り接続は確認しましたが、部屋作成・監視・両者のレート更新の権限は未検証です。Firebase設定やセキュリティルールは変更していません。既存ルールで許可されなければオンライン対戦は接続エラーになります。一人プレイには部屋へのアクセスは必要ありません。

今回の計算・集計はブラウザー内です。回答ログからスコアを再計算し入力形式を検証しますが、改変されたクライアントによる不正を防ぐサーバー認証にはなりません。公開競技として運用する場合は、認証されたユーザーとサーバー側の回答検証・結果確定が必要です。全ユーザーへの書き込みを無条件に許可するルールは追加しないでください。
