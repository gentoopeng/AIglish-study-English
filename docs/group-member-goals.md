# メンバーと協力目標

グループの「メンバー」（人型アイコン）にフレンド欄と同じ形式の一覧を表示します。
メンバーを押すとプロフィールを確認できます。写真は既存の共有キャッシュを利用します。
協力目標と達成の一覧はこの画面に残し、単語バトルは下へ配置します。

新しい目標は次から選び、1〜100000の整数で設定します。

- 理解度を付けた回数。同じ単語・意味への再回答も1回として数えます。
- 勉強時間（分）。
- 全員がそれぞれ達成（初期設定）。同じ目標値を各参加者が達成すると完了します。
- 全員の合計で達成。参加者の増加分を合計して判定します。

設定時の共有記録を開始値にし、学習終了・保存・グループ内の更新で共有します。
各人の進捗をレーン上のアイコンの位置で表示し、ゴール位置は100%で止めます。
表示のためのタイマーや新たな定期読み取りは追加しません。
モーション軽減設定では移動アニメーションを省略します。

理解度の「回数」は学習ランキングの既存記録に別の端末別カウンターを追加して保持します。
端末別の最大値をマージするため、同じセーブの再読み込みや再同期で二重加算しません。
過去の記録から回数を推測して補填しません。既存の単語数・スワイプ数・勉強時間の
ランキングは数え方とデータを変更せず、旧目標の種類「単語数」もそのまま表示します。
方式を持たない既存目標は従来の合計方式として扱います。

個人方式では他のメンバーの超過分を埋め合わせに使いません。
参加者追加・退会・勉強時間の訂正時には達成判定を再確認します。
合計方式では退会したメンバーの既存の貢献を維持します。
