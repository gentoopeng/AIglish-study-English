# ログイン時の10単語と共通UI

通常の `flashcard-play-screen` の画面構造をログイン時の学習にも使用します。
複製時にIDとインライン操作を取り除き、通常セッションのDOM・回答先へ干渉しないようにします。
カード面・長文サイズ調整・メモのブラー表示・スワイプ演出は共通関数を使用します。
ログイン時の回答は従来通り対象教材のWordDuelProgressジャーナルへ記録します。
「戻る」は直前の単語を再表示し、すでに記録した回答を削除しません。

アイコン写真はフレーム画像と同じ領域へ配置し、フレーム内側の透過形状に合わせた
`assets/frames/*-aperture.png` のアルファマスクで切り抜きます。
マスクは384pxの元画像の中心から透過領域を抽出し、境界を2pxだけ枠の下へ重ねています。
ブラウザー内での画像解析・canvas処理は不要です。8枚で合計約12KBです。
プロフィール・プレビュー・メニュー・フレンド・ランキングの共通装飾へ適用します。

フレンドとグループの一覧は、緑の操作色とアイコン、行の区切り、名前と補助情報の
2段表示で整理しました。取得頻度・グループ管理・対戦・学習記録の保存は変更しません。

10単語の終了後は、同じ位置に白い輪郭とセリフ体のSTARTカードを表示します。
タップすると左右の幕・リング・カードの拡大とフェードを約1秒で実行し、通常画面へ戻ります。
3D回転やぼかしは使わず、重複タップを防ぎ、タイマーでも確実に終了します。
モーション軽減時は演出を省略します。通常画面への復帰と終了時保存は既存処理を使います。
