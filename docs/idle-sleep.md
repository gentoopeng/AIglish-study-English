# 無操作スリープ

ログインの読み込み完了後、ポインター操作・キー入力・入力欄変更・スクロールを最後の操作として扱う。5分間無操作なら警告を表示し、操作がないまま10秒経つとスリープに入る。警告中の操作で解除する。アプリが非表示の間はタイマーを止め、再表示時に経過時間を確認する。

スリープでは最前面のダイアログで画面内を暗くする。端末本体の明るさ設定を変更する機能ではない。既存のプロフィールや設定ダイアログより前に表示し、再開ボタンで戻る。

勉強時間の直近の計測区間を端末内メモリに最大6分保持する。最後の操作から5分間にこの端末で実際に加算した区間だけを日付ごとに集計し、既存の日別編集方式で差し引く。未計測の時間・昔の記録・別端末が計測した区間は差し引かない。警告の10秒はこの5分補正には含めない。

補正後に勉強時間の計測を停止する。画面を描画してから端末保存をフラッシュし、既存の全体保存処理を1回呼ぶ。スリープ中は勉強時間の定期同期も停止する。通信・保存失敗は表示し、データをリセットしない。再開時はスリープ前の手動開始・一時停止状態に戻し、スリープ中の時間を加算しない。

Chromium／WebKitの仮想時計で5分＋10秒の境界、警告取消、保存1回、計測停止と再開、過去の時間保持、設定ポップ表示中のスリープを確認する。
