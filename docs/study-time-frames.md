# 合計勉強時間によるフレーム解放

| フレーム | 合計勉強時間 |
| --- | --- |
| 木 | 10分 |
| 石 | 1時間 |
| 銅 | 5時間 |
| 銀 | 20時間 |
| 金 | 50時間 |
| ダイヤ | 100時間 |
| プラチナ | 250時間 |
| ブラックダイヤ | 500時間 |

既存の勉強時間台帳を参照し、解放にコインや購入は不要。条件を満たした下位フレームも自由に装備できる。プロフィールを開いた時と装備時に条件を確認する。装備は既存のプロフィール保存・同期に含め、学習台帳を書き換えない。添付画像の透過WebPを使用する。

コイン表示・郵便ポスト・週間ランキング・報酬集計・専用カウンターの処理を削除した。累計ランキングと勉強時間画面の週間グラフは維持する。既存の理解度、学習台帳、単語帳、プロフィールを削除・リセットしない。古いコインや郵便の保存フィールドも破壊的な削除は行わず、参照しない。
