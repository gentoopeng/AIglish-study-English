# 学習ポイントの配分

今回のポイントは、勝率や勉強の才能ではなく、実際に行った学習を積み上げる指標とする。既存の獲得分を引き継ぎ、支出や賭け機能はこの変更に含めない。

| 行動 | 教材内の単語・日ごとの到達額 | 根拠 |
| --- | ---: | --- |
| 単語カードで理解度を記録（最初の10単語を含む） | 1pt | 自己申告のため小さく支給。○・△・×を同額にし、○を押す動機を作らない |
| 単語バトルで正解（シングル・対戦共通） | 3pt | 自己申告より高く、選択肢からの認識には小幅な加点 |
| 前日以前の苦手復習で正解 | 10pt | 日を空けた苦手の再学習を優先。既存の10ptを維持 |
| ワークの個別の理解度記録 | 1pt | 紙の学習結果を自己申告で記録。ページ・問題・小問は各1件 |
| アプリで実測した学習時間 | 1分につき1pt | 教材の長さで問題数が少なくなる学習も補助。手入力や昔の時間は除外 |

## 加算規則

- 日付は日本時間。単語は教材ID＋単語番号で識別し、意味違いも同じ単語として扱う。
- 同じ単語のカード1pt→バトル3pt→苦手復習10ptは差額1・2・7pt、合計10pt。別セッション、リセット、巻き戻し、再読込でも同日の権利は増えない。
- バトル誤答は0pt。得点・失点・コンボ・イベント・回答数ボーナス、人数、順位、試合時間で学習ポイントを倍率計算しない。回答済みのポイントは途中終了でも保持する。
- ログインだけ、ワークの一括変更やインポート、自由に設定できるグループ目標には追加報酬を付けない。
- 毎日の総額には上限を設けない。新しい対象に取り組んだ分と実測時間が増える。同じ対象を繰り返すだけでは増えない。
- 教材が異なる同名の単語は別教材の学習として扱う。自由に教材を作れるクライアントアプリであり、この仕組みを金銭価値や厳密な不正耐性のあるレートには使わない。

## 時間の扱い

既存タイマーの「表示中・計測対象・計測リーダー」の経過時間だけを、更新後から別フィールド `days[日本時間の日付].pointTime` に記録する。追加のポーリングやクラウド通信は行わない。手入力したカレンダー時間・旧オフセットは参照しない。

寝落ち時には実測分からも取り消しを記録する。日本時間の翌日0:06までは支給対象にしない。0:06以降の起動では端末の同期待ちに反映し、学習終了・スリープ・手動セーブで通常の同期処理に乗せる。1日分の実測ミリ秒を合算してから1分未満を切り捨てる。

端末ごとの累積計測値・取り消し値を5分単位で持ち、バックアップやクラウドとのマージはそれぞれ最大値を採用する。同じ5分区間に複数端末の記録がある場合は正味の計測が最も多い端末を採用する。重複による過剰支給を避ける方式であり、同じ5分区間内に端末を切り替えた場合は一部が支給対象にならないことがある。

## 比較例

- 新しい100単語をカードで記録、30分学習：単語100pt＋時間30pt＝130pt。
- その100単語も同じ日にバトルで正解：単語の到達額300pt＋時間30pt＝330pt。カードとバトルを足した430ptにはしない。
- 別の20単語を苦手復習で正解、30分学習：200pt＋時間30pt＝230pt。
- ワークを20件個別に記録、60分学習：20pt＋時間60pt＝80pt。

問題の難易度や学習効果を完全に測るものではない。自己申告や受動的な時間だけで増えすぎないようにし、翌日以降の復習への動機を強くする初期配分としている。

## 保存と読み取り

既存 `learningPoints/main` と `reviewPointDays` の日別シャードを引き継ぐ。各対象の到達額をトランザクションで比較し、差額のみを残高へ加算する。旧10ptの数値・真偽値の記録も読み込める。時間は計測値を日別シャードでマージしてから差額を決定する。確定済み残高と未同期の差額を分け、旧バックアップ復元・応答消失・別端末の再送を重複支給しない。

クラウドが古い、利用上限、通信失敗、破損データの場合は未同期記録を残す。回答やタイマーのtickのたびにクラウドへ書かない。通常の20単語の支給は既存方式同様、ウォレットと1シャードの計2ドキュメントの読み取りで処理できる（アカウントの削除確認など既存ガード分を除く）。履歴は対象・日ごとの合計で最近100件。時間の生計測は履歴へ重複保存しない。

クライアント内のポイント計算であるため、開発者ツールや不正なクライアントの改変まで防ぐ権威的なサーバー検証ではない。
