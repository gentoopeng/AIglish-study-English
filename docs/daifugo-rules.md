# 大富豪のルール（実装の元）

出典: 日本大富豪連盟「公式ルールブック」 https://daifugojapan.com/rule-book （制定 2026-04-06、最終改訂 2026-11-04）。条文番号は Art.。公式は 4 人制が基本で、3 人制・5 人制は「準公式」。

## 人数・カード・配り
- 4 人（基本）: 54 枚（通常札 52 + ジョーカー 2）。ブラインドカード 2 枚（ジョーカー以外）を抜き、13 枚ずつ。順位は 大富豪・富豪・貧民・大貧民。
- 3 人（準公式）: 通常札 39 + ジョーカー 1 = 40 枚、ブラインド 1 枚、13 枚ずつ。どの 39 枚かは公式に書かれていないので、この実装は ♤♡◇ の 3 スートを使う。順位は 富豪・平民・貧民。革命は同ランク 3 枚。
- 5 人（準公式）: 54 − ブラインド 4 = 50 枚、10 枚ずつ。順位は 大富豪・富豪・平民・貧民・大貧民。
- 2 人・6 人は公式にない（この実装は 3〜5 人）。

## 強さ
- 通常: 3 < 4 < … < 10 < J < Q < K < A < 2 < JK
- 革命中: 2 < A < K < … < 4 < 3 < JK（ジョーカーは常に最強）
- 同じ強さは出せない（Art.27）。

## 出し方
- 単体 / ペア / トリプル / 4 枚以上（同ランク）/ 階段（同スート 3 枚以上、連続）。
- 場には同じ枚数・同じ構成（階段なら階段）で、より強いものだけを出せる。階段の強さは一番低い札。
- 階段: Q-K-A と K-A-2 は有効、A-2-3 は無効。革命中は 3-4-5 が有効（強さは逆）。
- ジョーカーは同ランクの足りない札の代わりになる。階段の中や端にも入れられる（複数の読み方があるときは一番強い読み）。ジョーカー単体は最強の単体。JK+JK は最強のペア（場が流れる）。
- 最強階段（ジョーカーを一番上に: A-2-JK、K-A-2-JK など。革命中は 3-4-JK）は場が流れる。
- パスは場にカードがあるときだけ。一度パスしたら、その場が流れるまで出せない。場が空のとき（スターター）はパスできない。

## 場が流れる（Art.17）
全員がパス / 8 切り / スペ 3 返し / 最強階段 / JK のペア / 同ランク 4 枚+JK2（シックスカード）。流れたあとは、最後に出した人が先頭（その人が上がっていたら左隣）。

## 特別ルール
- 8 切り: 8 だけの出し方（階段は除く。8+JK のペアも 8 切り）で場が流れ、出した人が続けて先頭。
- スペ 3 返し: ジョーカー単体にはスペード 3 の単体だけが勝つ。場が流れる。革命中・縛り中でも使える。
- 革命: 同ランク 4 枚以上（ジョーカーを含む形も可。3 人制は 3 枚）で強さが逆になる。もう一度革命で戻る（革命返し）。ゲームの終わりまで続く。革命は縛りを解かない。
- 縛り: 同じスート（の組み合わせ）が続けて出されると、そのスートしか出せなくなる。場が流れると解ける。ジョーカーは縛りの助けにはなるが、縛りを始めることはできない。（連続回数の指定は公式にないため、実装は「直前と同じスートの組み合わせで出された時」に縛りを始める。）
- 反則上がり（最後の出し方が次のとき）: 通常時の 2 を含む / 8 切りになる出し方 / ジョーカーを含む / スペ 3 の単体。革命中は 3 を含む出し方。反則上がりした人は最下位側に回る（最初に反則した人が大貧民、2 人目が貧民、3 人目が富豪）。その人はゲームから抜ける。
- 都落ち: 前のゲームの大富豪が、次のゲームで最初に（反則でなく）上がった他の人がいたとき、大貧民になる。セットの 1 ゲーム目には適用しない。

## カード交換（ゲームの前）
- セットの 1 ゲーム目はなし。2 ゲーム目以降、同時に交換。
- 大富豪 ↔ 大貧民: 2 枚。富豪 ↔ 貧民: 1 枚（3 人制は 富豪 ↔ 貧民 の 1 枚）。5 人制の平民は交換なし。
- 下位の人は持っている中で一番強い札から渡す（ジョーカー > 2 > A > K …）。上位の人は好きな札を渡す。

## 進行
- 1 ゲーム 1 位から最後まで順位が決まるまで。1 セット = 4 ゲーム（公式）。
- ゲーム 1: スペードの席の人から。2 ゲーム目以降: 前のゲームの大貧民から。
- 得点（4 人制）: 大富豪 6 点・富豪 4 点・貧民 2 点・大貧民 0 点。セットの最終ゲームの大富豪は +2 点。

## 公式に書かれていない点（実装の決め）
- 縛りの始まり: 上に書いたとおり。
- ジョーカー単体の 8 切り: ならない（8 を含む出し方のみ）。
- 4 枚の出し方に勝てるもの: 同じ枚数の、より強い同ランク。
- JK+JK+札 は、トリプルとして扱う（階段の読みは出し手が選ぶ）。
